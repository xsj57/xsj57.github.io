Raspberry Pi Face Recognition Unlock System

Face recognition unlock workflow for Mac

This project uses a Raspberry Pi and camera to recognize authorized faces, trigger a local service, and unlock a Mac over the network through a controlled workflow.

1. Overview

The system combines computer vision, Raspberry Pi hardware, and a small web control layer. It is designed for local-network use, with configuration for authorized users, Mac connection details, camera capture, model training, and runtime logs.

2. Features

Core features include face recognition with the face_recognition library, Mac remote unlock support, a mobile-friendly web interface, manual and scheduled trigger modes, real-time monitoring, and service scripts for auto-start and restart after failures.

3. Deployment Flow

The workflow starts by configuring the Mac connection, collecting face data, training the recognition model, and then running the unlock service from the command line or web interface. The repository also includes deployment and service-management documentation for Raspberry Pi 4/5 setups.
